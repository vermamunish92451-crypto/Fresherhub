# FresherHub - Data Science Learning Platform

A beginner-friendly platform for learning Data Science from scratch, with real code examples and interactive tutorials.

## Features

- Python Basics to Advanced (OOP, File Handling, Exception Handling)
- Python Libraries (NumPy, Pandas, Matplotlib, Seaborn)
- SQL (Queries, Joins, Subqueries, Aggregations)
- Power BI (DAX, Dashboards, Visualizations)
- Machine Learning (Regression, Classification, Clustering)

## Project Structure


## Getting Started

### Website

Open `Website/index.html` in your browser to view the FresherHub learning platform.

### Python Scripts

```bash
# Install dependencies
pip install -r requirements.txt

# Generate resume PDFs
python src/generate_resume.py
python src/generate_resume_aiml.py
```

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Python 3
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, FPDF2
- **Tools:** Power BI, SQLite, Streamlit
